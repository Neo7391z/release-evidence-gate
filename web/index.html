    Run your own isolated audit

    This creates a new free Studionet contract and submits one synthetic evidence snapshot. A disposable signer stays in memory only. No browser wallet or real tokens. Allow several minutes for validator consensus. Refreshing loses control of this disposable contract.

    How to reproduce
    The app reads finalized records directly from the public GenLayer SDK. Run the repository's CLI to deploy an isolated, zero-fee Studionet ledger and audit the supplied synthetic releases. The CLI signs with a disposable local signer, waits for finality, verifies a five-validator majority, checks source code, and saves receipts. The optional isolated-demo button signs only free Studionet transactions after an explicit click.
    Security boundary: maintainers choose evidence. Quotes prove attribution to those snapshots, not factual truth. Incomplete evidence requires review; explicit failures block documentary acceptance. The contract never performs a deployment.
